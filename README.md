# Cubillo Moya (com.cubillomoya.gastos)

Proyecto Android Kotlin WebView generado con **WebDroid Studio**.
Incluye el puente nativo `window.WebDroid` (`toast`, `vibrate`, `setStatusBarColor`, `share`, `getDeviceInfo`).

## Compilar el archivo .apk
1. Sube este proyecto a un repositorio en GitHub (incluyendo `.github/workflows/build-apk.yml`).
2. En **Actions**, ejecuta **Compilar APK Android** y descarga `com.cubillomoya.gastos-apk` con `app-debug.apk`.
3. O ábrelo en Android Studio: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
